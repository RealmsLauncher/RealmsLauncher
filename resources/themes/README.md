# Built-in Community Themes

This directory contains community-created themes for RealmsLauncher.

## Directory Structure

- `themes/` - Qt StyleSheets (.qss) theme files
- `icons/` - Icon pack sets
- `cats/` - Cat pack cosmetics

All themes are CC0 licensed (public domain) from the PrismLauncher community.

## Using Custom Themes

1. Launch RealmsLauncher
2. Go to Settings → Appearance
3. Select a theme from the dropdown
4. Restart the launcher to apply
